Conceitos Chave (Lista de Definição)

ARPANET
A rede de computadores inicial desenvolvida pelo Departamento de Defesa dos EUA que deu origem à Internet.
TCP/IP e DNS
O TCP/IP é o conjunto de protocolos de comunicação, enquanto o DNS é o sistema que traduz nomes de domínio em endereços IP (ex: IPv4 e IPv6).
World Wide Web (WWW)
Sistema de documentos interligados em hypertexto executados sobre a Internet, criado por Tim Berners-Lee no CERN.

Linha do Tempo dos Marcos Históricos

Linha do Tempo da Evolução da Web
Ano Acontecimento Importância para a Web/Internet
1969 Surgimento da ARPANET Primeira conexão realizada entre computadores distantes.
1983 Adoção do protocolo TCP/IP Estabeleceu o padrão oficial para a rede de computadores (Internet).
1989 Proposta da WWW por Tim Berners-Lee Nascimento da World Wide Web no laboratório do CERN.
1991 Lançamento do primeiro Servidor Web e Navegador Disponibilização da Web para uso público e acadêmico.
1994 Fundação do W3C Criação do consórcio responsável por padronizar o HTML e as tecnologias Web.
2004+ Transição para a Web 2.0 (Aplicações Web Modernas) A Web deixa de ser apenas leitura e passa a ser interativa e colaborativa.
